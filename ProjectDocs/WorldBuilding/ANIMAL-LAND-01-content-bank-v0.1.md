# 애니멀랜드 콘텐츠 후보 뱅크 v0.1

> World ID: `ANIMAL-LAND-01`
>
> 문서 상태: Candidate Draft
>
> 작성 기준일: 2026-08-10
>
> 선행 문서: [`ANIMAL-LAND-01-world-expansion-draft.md`](./ANIMAL-LAND-01-world-expansion-draft.md)

이 문서는 애니멀랜드의 확정 입력을 바탕으로 신규 용병과 적대 콘텐츠 후보를 생산하기 위한 아이디어 뱅크다.
여기에 이름이 올라간 것만으로 정식 캐릭터나 제작 대상이 되지는 않는다. 사용자가 제외하지 않은 후보는 향후
필요한 역할과 제작 난이도에 맞춰 하나씩 꺼내 사용할 수 있다.

## 1. 후보 생성 원칙

- 원형 동물, 직업, 무기와 전투 역할이 서로 중복되지 않게 한다.
- 동물의 익숙한 성향을 첫인상으로 사용하되, 개인 성격을 하나 더 부여한다.
- 플레이어 캐릭터는 평화 진영을 기본으로 하며, 강경 진영 출신 이레귤러는 초기 후보에서 남발하지 않는다.
- 적대 콘텐츠는 감염 전부터 적대적인 강경 진영 구성원을 기본으로 한다.
- 적을 단순 전사만으로 구성하지 않고 약탈, 매복, 독, 저주, 공성, 자원 착취로 역할을 분산한다.
- 작은 데스크탑 표시 크기에서 원형 동물과 직업이 동시에 읽혀야 한다.
- V2 제작 난이도는 `낮음 / 보통 / 높음`으로만 분류하며 실제 제작 전에 별도 Brief에서 다시 평가한다.

## 2. 기존 콘텐츠 기준점

신규 후보는 아래 기존 콘텐츠와 외형·역할이 그대로 겹치지 않아야 한다.

### 기존 평화 진영 캐릭터

| Actor | 핵심 식별 요소 | 신규 후보가 피해야 할 직접 중복 |
|---|---|---|
| `CatKnight` | 고양이 기사 | 동일한 고양이 + 정통 검기사 |
| `BlackCatMage` / `CatMage` | 검은 고양이, 뾰족 모자, 지팡이 | 동일한 고양이 + 원소 마법사 |
| `RabbitHealer` | 흰 토끼, 어린 힐러, 짧은 완드 | 동일한 소형 동물 + 직접 치유 전담 |
| `DogShieldWarrior` | 충직한 개, 방패전사 | 방패만을 정체성으로 삼는 수호자 |
| `FoxArcher` | 영리한 여우, 활 | 일반적인 활 기반 척후병 |
| `DragonWarrior` | 용인, 양손검 | 대형 파충류 + 양손검 전사 |

| Actor | 확정·잠정 역할 | 후속 방향 |
|---|---|---|

## 세계관 역할

- 평화 진영의 숲과 국경 지대를 순찰한다.
- 정규군의 영토 확장보다 침입 흔적 추적, 주민 대피와 길목 봉쇄를 담당한다.
- 강경 진영의 굴착대가 보호림 아래의 자원을 훔치는 사건을 추적할 수 있다.
- 버그에 오염된 균열과 감염체를 뒤쫓다가 데스크탑에 도착한다.
- 백신의 보호를 받고 용병단과 협력해 감염체의 이동을 제한한다.
- 장기 목표는 감염 경로를 차단하고 애니멀랜드의 숲으로 돌아가는 것이다.

국가명, 숲의 정식 지명과 개인 이름은 현재 생산에 필요하지 않아 확정하지 않는다.

## 캐릭터 해석

동물 우화의 `신중하고 경계심이 강한 사슴`이라는 첫인상을 사용하되, 겁이 많아 도망치는 캐릭터로 만들지
않는다. 침입자의 흔적을 발견하면 위험을 감수하고 끝까지 추적하는 집요함이 개인 성격이다.

## 게임 역할과 전투 표현

- 직접 치유가 아닌 제어형 보조 전투원이다.
- 적의 이동 경로를 묶거나 밀어내는 표현을 사용한다.
- 지팡이 타격과 뿔 받아치기를 결합한 중거리 근접 전투를 한다.
- 숲 마법은 덩굴, 잎과 뿌리의 짧은 이펙트로 표현한다.
- Master와 Idle에는 상시 마법 이펙트를 포함하지 않는다.

## 얼굴과 종족 특징

- 인간 얼굴에 귀와 뿔만 붙인 형태가 아닌 짧고 부드러운 사슴 주둥이를 사용한다.
- 코는 작은 짙은 갈색 또는 검은색 덩어리다.
- 눈은 따뜻한 호박색이며 경계하는 인상을 유지한다.
- 귀는 머리 양옆 위쪽에서 바깥으로 벌어지고 뿔에 완전히 가려지지 않는다.
- 뿔은 좌우가 같은 계열이며 3/4 시점의 원근 차이만 허용한다.
- 한쪽 뿔당 큰 가지 1개와 읽기 쉬운 가지 끝 2~3개만 사용한다.
- 털은 따뜻한 적갈색이며 주둥이, 목과 꼬리 아래는 밝은 크림색이다.

## 의상과 장비

### 의상

- 짙은 숲색의 짧은 천 튜닉
- 갈색 가죽 조끼와 허리띠
- 소형 가죽 손목·다리 보호구
- 화면 왼쪽으로 내려오는 올리브색 한쪽 어깨 망토
- 황동색 원형 망토 고정핀 1개

승인 Master의 망토 길이는 허벅지 중간 부근까지다. 다리와 꼬리를 가리지 않으므로 그대로 유지한다.

### 지팡이

- 한손·양손 겸용의 짧고 곧은 목재 지팡이 1개
- 캐릭터의 뿔 제외 신장 대비 약 0.8~0.9 길이
- 지팡이 위쪽만 갈라진 나뭇가지 형태
- 갈라진 끝 사이에 작은 청록색 마법석 1개
- 날붙이와 창날이 없음
- Master 기준 화면 오른쪽 손에 세로로 든다.

## 승인 실루엣

작은 화면에서 다음 순서로 읽혀야 한다.

1. 단순한 수사슴 뿔
2. 길고 열린 귀와 짧은 주둥이
3. 세로로 든 나뭇가지 지팡이
4. 한쪽 숲 망토와 갈라진 발굽

뿔 끝과 지팡이 끝은 서로 겹치지 않는다.

## V2 팔레트

| 영역 | 승인 방향 |
|---|---|
| 털 | 따뜻한 적갈색과 황갈색 |
| 밝은 털 | 크림색 |
| 뿔·지팡이 | 중간 갈색과 어두운 적갈색 |
| 튜닉·망토 | 숲 녹색과 올리브색 |
| 가죽 | 짙은 갈색 |
| 금속 | 저채도 황동색 소량 |
| 눈 | 호박색 |
| 마법석 | 밝은 청록색 1개 |

V2 최종 프레임은 IceMage의 실제 42색을 참고해 투명색 제외 약 32~48색 범위를 목표로 한다. 고해상도
Master의 색상 수를 직접 양자화하지 않고 PerfectPixel 출력과 후가공 단계에서 확정한다.

## 절대 바뀌면 안 되는 요소

- 수사슴으로 읽히는 단순한 뿔, 긴 귀, 짧은 주둥이와 발굽
- 따뜻한 갈색 털과 밝은 주둥이·목 털
- 짙은 녹색 튜닉, 갈색 가죽 조끼와 한쪽 올리브색 망토
- 날이 없는 나뭇가지형 목재 지팡이 1개
- 지팡이 끝의 작은 청록색 마법석 1개
- 화면 오른쪽을 향하는 약한 3/4 전신 자세
- 침착한 수호자 인상
- 뿔, 귀와 지팡이가 분리된 실루엣

## 금지 요소

- 인간 얼굴에 사슴귀와 뿔만 추가한 디자인
- 거대한 엘크형 또는 지나치게 복잡한 다갈래 뿔
- 뿔의 꽃, 잎, 보석과 장신구
- 활, 화살통, 검, 창, 글레이브와 날이 달린 지팡이
- 긴 로브, 발목까지 오는 망토와 중판금 갑옷
- 네 발 사슴, 켄타우로스와 해골사슴 형태
- 상시 발광 문양, 대형 오라와 Master·Idle의 마법 이펙트
- 배경, 외부 그림자, 바닥, 문자와 UI 요소

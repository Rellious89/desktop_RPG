## 세계관 역할

- 종족 전쟁의 확장보다 다친 주민과 동료를 돌보는 평화 진영의 생활형 치유사다.
- 전투에 참가하더라도 적을 쓰러뜨리는 과시보다 회복과 생존 보조가 먼저 읽힌다.
- 버그 감염으로 위협 대상이 데이터와 데스크탑까지 번진 뒤 용병단에 합류할 수 있다.
- 정확한 부족명, 고향 지명과 개인 이름은 아직 정하지 않는다.

## 체형과 종족 특징

| 항목 | 기존 설정값 |
|---|---|
| 체격 | tiny / slender |
| 비율 | humanoid SD 약 2.5등신 |
| 목표 신체 높이 | 귀를 제외하고 논리 높이 65px |
| 털 | 흰색 |
| 눈·포인트 | 분홍색 계열 눈, 코와 귀 안쪽 |
| 귀 | 길고 곧은 양쪽 귀, 양쪽 안쪽 분홍색이 모두 보임 |
| 손·발 | 작은 손, 중간 크기의 맨발 토끼발 |

전체 크기는 머리부터 발끝까지를 기준으로 판단하고 긴 귀는 별도 종족 장식으로 취급한다. 귀를 포함한 전체
실루엣 때문에 몸통을 다른 소형 캐릭터보다 축소하지 않는다.

## 의상과 장비

- 하늘색의 가벼운 반팔 티셔츠
- 노란색 멜빵 호박바지
- 몸을 가로지르는 작은 갈색 크로스백
- 분홍색 머리핀 1개
- 맨발
- 화면상 오른손에 든 짧고 가벼운 한손 나무 완드 1개

의상은 부족 생활의 소박함을 유지하며 금속 갑옷, 긴 로브와 대형 장식은 사용하지 않는다.

## 실루엣 우선순위

1. 신체 스케일과 분리해서 읽히는 긴 토끼 귀
2. 큰 토끼 머리와 작은 몸
3. 노란 멜빵 호박바지
4. 짧은 나무 완드와 갈색 크로스백

귀, 완드와 가방은 서로 겹쳐 하나의 덩어리가 되지 않아야 한다.

## 팔레트

| 영역 | 고정 방향 |
|---|---|
| 털 | 따뜻한 흰색과 크림색 명암 |
| 귀·얼굴 포인트 | 분홍색 |
| 상의 | 밝은 하늘색 |
| 멜빵바지 | 따뜻한 노란색 |
| 가방·완드 | 중간~짙은 갈색 |

## 변경 불가 요소

- 흰 토끼 수인과 어린 여성 인상
- 양쪽 안쪽 분홍색이 보이는 두 개의 긴 귀
- 귀를 제외한 신체 크기 판정
- 하늘색 반팔티와 노란 멜빵 호박바지
- 작은 갈색 크로스백과 분홍색 머리핀
- 짧은 목재 완드 1개와 맨발
- 화면 오른쪽을 향하는 3/4 전신

## 금지 요소

- 귀를 포함해 몸을 과도하게 축소하는 프레이밍
- 한쪽 귀 안쪽이 완전히 가려지는 정면·측면 각도
- 마녀 모자, 긴 로브, 금속 갑옷과 현대 장비
- 지팡이 추가, 대형 성직자 봉과 날붙이 무기
- Master와 Idle의 대형 마법 이펙트, 배경, 외부 그림자와 문자
- 성숙하거나 관능적인 성인 체형

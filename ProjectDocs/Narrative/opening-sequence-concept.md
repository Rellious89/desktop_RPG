# KeyBuddy 오프닝 연출 콘셉트

> 문서 상태: Opening Concept v0.1 / 2026-07-24
>
> 용도: 추후 게임 오프닝 제작을 시작할 때 사용할 스토리보드 초안
>
> 구현 상태: 기획 보관 / 제작 일정 미정

이 문서는 최초 실행 시 이세계 몬스터가 사용자의 데스크탑을 침공하고, 첫 용사가 도착해 자리를 잡는 과정을
대사 없이 보여주기 위한 연출안이다. 세부 컷 길이, 카메라, 사운드와 실제 등장 Actor는 제작 착수 시 확정한다.

상위 세계관 설정은 [`world-setting-rules.md`](../DesignRules/world-setting-rules.md)를 따른다.

## 1. 연출 목적

- 게임의 무대가 판타지 세계가 아니라 **사용자의 실제 데스크탑**임을 보여준다.
- 오염된 균열을 통해 이세계 몬스터가 침입한다는 사실을 전달한다.
- 용사도 다른 세계에서 넘어오지만, 안정된 균열과 친근한 행동으로 몬스터와 구분한다.
- 주인공이 데스크탑에 정착하고 허수아비 훈련을 시작하는 순간을 실제 게임 플레이와 연결한다.
- 거대한 설명이나 메인 스토리 없이 키 입력만으로 첫 상호작용을 시작하게 한다.

## 2. 최초 오프닝 시퀀스

### A. 데스크탑 침공

1. Unity 로고가 사라지고 화면이 암전된다.
2. 실제 데스크탑으로 전환된 뒤 짧은 노이즈와 글리치가 발생한다.
3. 화면 오른쪽 아래에 오염된 시공의 균열이 열리며 치지직거린다.
4. 균열에서 보라색 오류 기운을 두른 첫 감염체가 나타난다.
5. 선택 연출로 마우스 포인터 또는 포인터를 닮은 게임 내 표현이 이상을 감지하고 접근한다.
6. 화면 곳곳에 추가 균열이 열리고, 균열 너머로 서로 다른 연결 세계가 짧게 비친다.
7. 각 세계에서 넘어온 다양한 몬스터의 실루엣이 데스크탑을 점령한다.

### B. 의문의 용

8. 화면 왼쪽에 거대한 균열이 열린다.
9. 거대한 용이 나타나 화면을 일직선으로 가로지르며 브레스를 발사한다.
10. 브레스가 침입한 몬스터들을 일망타진한다.
11. 용은 데스크탑에 머물지 않고 균열 너머로 사라진다.
12. 화면에 짧은 정적이 흐른다.

용의 정체는 오프닝에서 설명하지 않는다. 현재 우선 후보는 과거 데스크탑에서 성장을 마치고 원래 세계로
돌아간 **선대 용사**다. 이 설정은 용 또는 귀환 콘텐츠를 실제 제작할 때 확정한다.

### C. 첫 용사의 도착

13. 화면 가운데 작은 지직거림이 생기고 점차 커진다.
14. 앞선 오염된 균열보다 작고 안정적인 시공의 균열이 천천히 열린다.
15. 아직 미정인 귀여운 주인공 캐릭터가 얼굴만 내밀어 데스크탑을 살핀다.
16. 주인공이 조심스럽게 걸어 나오거나, 허공에서 잠시 허우적대다 바닥에 떨어진다.
17. 주인공은 주변을 두리번거린 뒤 화면 오른쪽의 빈자리로 걸어간다.
18. 침공 중 쓰러진 훈련용 허수아비를 발견하고 다시 세운다.
19. 주인공이 허수아비 앞에서 훈련 자세를 잡고 첫 키 입력을 기다린다.
20. 사용자가 키를 입력하면 주인공이 허수아비를 공격하며 실제 게임이 시작된다.

## 3. 반복 용사 소환 연출

- 화면 한편의 타이머가 다음 연결 좌표의 안정화까지 남은 시간을 표시한다.
- 시간이 끝나면 해당 위치에 오프닝과 같은 안정된 시공의 균열이 열린다.
- 새로운 이세계 용사가 균열에서 튀어나와 데스크탑 거점에 합류한다.
- 반복 연출은 최초 오프닝보다 짧게 구성하며, 용사별 등장 성격을 작은 동작으로 변주할 수 있다.
- 정확한 타이머 조건, 소환 확률, 중복 처리와 스킵 기능은 캐릭터 획득 시스템 설계 시 확정한다.

## 4. 향후 전투 모드 연결

- 평상시는 데스크탑 거점에서 허수아비를 공격하며 훈련하는 상태다.
- 전투 모드에서는 오염된 균열에서 버그와 감염체가 쏟아져 나온다.
- 여러 세계의 용사들은 훈련과 전투로 성장하고 이세계 용병단의 전력을 키운다.
- 성장을 마치고 사명을 완수한 용사는 원래 세계로 귀환해 자신의 세계를 지킨다.
- 귀환 뒤에도 동기화 데이터 또는 연결 기록이 유지되므로 관리자는 해당 용사와 계속 교감하고 사용할 수 있다.

## 5. 제작 전 확정할 항목

- 첫 주인공 Actor와 등장 동작: 걸어 나오기 또는 허우적대다 떨어지기
- 거대한 용의 정체, 디자인, 출신 세계와 재등장 여부
- 오프닝에 사용할 몬스터 실루엣 목록과 각 균열 너머의 세계
- 감염체의 보라색 오류 기운 및 오염된 균열의 공통 시각 규칙
- 안정된 균열과 오염된 균열의 색상, 형태, 사운드 차이
- 허수아비가 쓰러진 이유와 주인공이 세우는 동작의 프레임 구성
- 실제 OS 포인터 사용 여부와 사용자의 마우스를 강제로 움직이지 않는 표현 방식
- 스킵, 재시청, 최초 실행 판정과 오프닝 종료 후 게임 상태 연결
- 컷별 길이, 사운드, 암전과 글리치 강도 및 광과민성 접근성 옵션

## 6. 제작 주의사항

- 오프닝 몬스터 군중은 실제 제작된 몬스터 리소스의 실루엣을 우선 재사용한다.
- 훈련용 허수아비와 감염된 허수아비 몬스터는 명칭과 시각 표식으로 명확히 구분한다.
- 마우스 연출이 필요하면 실제 OS 포인터를 강제로 이동시키지 않고 가짜 포인터나 주변 반응 효과를 우선한다.
- 보라색 기운과 글리치는 버그 오염의 표식으로 사용하며 모든 차원 균열의 공통 속성으로 만들지 않는다.
- 주인공이 화면 오른쪽에 자리 잡는 마지막 위치는 실제 기본 게임 배치와 일치시킨다.
- 연출 종료 직후 별도 설명창 없이 첫 키 입력이 허수아비 공격으로 자연스럽게 이어져야 한다.
- 이 문서는 연출 콘셉트이며, 실제 기능이 확정되기 전 세부 세계관을 추가로 고정하지 않는다.

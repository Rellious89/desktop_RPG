# TMP 가독성 비교 랩 완료 보고

## 구현 결과

- `UNITY_EDITOR` 또는 `DEVELOPMENT_BUILD`에서만 컴파일·부트스트랩되는 런타임 비교 오버레이를 추가했다.
- 씬/프리팹 배선 없이 자동 생성되며, 시작 시 숨겨져 있다.
- F8을 `GlobalKeyboardHook`의 공격 제외 키로 등록하고 `WasExcludedKeyDownThisFrame`으로 토글한다. 에디터의 최소 테스트 씬에서도 포커스 입력으로 사용할 수 있도록 fallback을 둔다.
- Screen Space Overlay + 최고 우선 sorting canvas를 사용하며, 생성된 Graphic은 raycast를 받지 않는다.
- 로드된 `TextMeshProUGUI`에서 `Mulmaru SDF`와 `Mulmaru SDF Outline B`를 우선 찾고, 없으면 TMP 기본 폰트/머티리얼로 폴백하며 화면 하단 진단 문구를 표시한다.
- `한글 Aa 0123` 샘플을 8/10/12 크기로 표시하고 다음 네 가지 런타임 머티리얼 복제본을 비교한다.
  1. 현재 기준값
  2. 외곽선 강화
  3. 얇은 외곽선 + 단단한 Underlay
  4. 현재 외곽선 + 단단한 Underlay
- 메인 샘플 행은 불투명 패널 없이 실제 투명 윈도우 배경 위에 표시하고, 제목·후보명에만 어두운 보조 배경을 둔다.
- 밝은 배경·어두운 배경 스와치에는 네 후보를 모두 표시한다. 패널 바깥은 실제 투명 윈도우 배경을 확인할 수 있다.
- 후보 설정값은 런타임 오브젝트의 `Candidate Config`에서 조정 가능하다. 기존 폰트 에셋, 공용 머티리얼, 게임 UI에는 값을 쓰지 않는다.
- Underlay 기본값은 TMP 드롭 섀도우 프리셋에 맞춰 X `0.5`, Y `-0.5`, Softness `0`, 검정 알파 `0.9`, Dilate `0`으로 두며 후보명 옆에 오프셋·Dilate가 표시된다.
- 오버레이 종료 시 모든 머티리얼 복제본을 파괴한다.

## 수동 Windows 확인

1. Development Build 또는 에디터 Play Mode를 실행한다.
2. 게임 창에 포커스가 없는 상태에서 F8을 누르고 오버레이가 켜지는지 확인한다.
3. 밝은 바탕화면에서 8/10/12 크기와 네 후보의 외곽선 가독성을 비교한다.
4. `LIGHT WALLPAPER`와 `DARK WALLPAPER` 샘플을 기준으로 Underlay 후보의 번짐·지저분함을 확인한다.
5. F8로 닫은 뒤 일반 게임 UI의 폰트가 변하지 않는지 확인한다.
6. 씬 전환 후에도 F8 토글이 유지되는지 확인한다.

## 검증

- 순수 후보 설정/크기/부트스트랩 게이트 EditMode 테스트를 추가했다.
- 기존 공용 TMP 에셋·머티리얼, 로컬라이즈 테이블, 씬 배선은 변경하지 않았다.

# KeyBuddy 건축물 기능 해금 보류 작업 목록

## 문서 목적

이 문서는 캐릭터·퀘스트 중심 개발을 우선하는 동안 건축물 기능 해금 트랙에서 보류한 작업을 보존한다.

- 현재는 신규 건축물 기능 구현을 중단한다.
- 기존 건축물과 공통 건축 시스템은 삭제하거나 되돌리지 않고 기반 기능으로 유지한다.
- 대표 캐릭터의 획득부터 귀환까지 이어지는 경험과 조건 기반 퀘스트 구조를 먼저 검증한다.
- 건축물 작업을 재개할 때 이 문서를 기준으로 명칭·역할·우선순위를 다시 조정한다.

이 문서는 구현 지시서가 아니다. 수치, 비용, 해금 순서와 세부 효과는 재개 시점에 다시 확정한다.

## 보류된 핵심 후보

### 1. 대장간

초기 목적은 아이템 강화 기능과 아이템·재료의 직접적인 소비처 제공이었다.

캐릭터·퀘스트 중심 방향에서는 단순 공격력 강화 시설로 먼저 구현하지 않는다. 아래와 같은 실제 캐릭터 콘텐츠 요구가 생길 때 다시 검토한다.

- 특정 장비의 강화 상태가 캐릭터 등장 조건이 되는 경우
- 장비가 캐릭터 전용 스킬 또는 이벤트를 해금하는 경우
- 캐릭터 개인 퀘스트나 귀환 조건에 가공·강화가 필요한 경우
- 던전 보상 재료의 의미 있는 소비처가 필요한 경우

재개 전 결정할 사항:

- 강화 대상이 장비인지, 퀘스트용 핵심 아이템인지
- 강화가 전투력 상승인지 콘텐츠 조건 해금인지
- 성공률·실패·단계 하락 같은 확률 시스템을 사용할지
- 비용이 재화인지 재료 아이템인지
- 캐릭터별 조건식과 강화 결과를 어떤 공통 데이터 계약으로 연결할지

### 2. 광산

초기 목적은 대장간과 제작에 필요한 재료 아이템을 생산하는 것이었다.

광산은 독립적인 필수 시설로 먼저 만들지 않는다. 대장간이나 캐릭터 퀘스트에서 실제로 지속적인 재료 공급이 필요해질 때 함께 검토한다.

재개 전 결정할 사항:

- 시간 기반 자동 생산인지 용병 배치형 생산인지
- 온라인·오프라인 경과를 모두 인정할지
- 생산 슬롯과 보관 한도가 필요한지
- 재료를 던전에서도 얻을 수 있는지, 광산만의 독점 재료가 있는지
- 광산 관리가 방치형 컴패니언 흐름에 과도한 반복 조작을 요구하지 않는지

대장간에 재료 소비가 없거나 캐릭터 퀘스트에 채굴 자원이 필요하지 않다면 계속 보류한다.

## 확장 기획 후보

아래 항목은 초기 아이디어가 있었지만 현재 MVP의 필수 기능으로 확정하지 않는다.

### 휴식용 여관

현재 용병 모집 기능을 가진 `여관`과는 별개의 초기 기획이다.

- 행동력·포만감·정신력 등을 전문 시설보다 낮은 효율로 일괄 회복
- 여러 상태를 한곳에서 관리하는 범용 휴식 시설

현재 포만감과 정신력은 확정 시스템이 아니며 행동력은 회복소가 담당한다. 따라서 별도 휴식용 여관은 관련 캐릭터 상태가 실제 콘텐츠로 채택되기 전까지 구현하지 않는다.

### 주점

- 전투·임무 실패 등으로 쌓인 스트레스 해소
- 술 또는 도박 이용
- 잦은 이용에 따른 도덕성 감소
- 스트레스에 따른 경험치 획득 불이익
- 도덕성에 따른 퀘스트 보상 변화

스트레스와 도덕성은 모두 미확정 상태다. 캐릭터 개성과 퀘스트 결과를 실제로 다르게 만드는 데 필요하다고 판단될 때 하나의 묶음으로 재기획한다.

### 교회 확장

현재 구현된 오염도 정화 외에 다음 아이디어가 있었다.

- 기도·헌금을 통한 도덕성 회복
- 정신 상태 관리
- 오염 관련 캐릭터 이벤트 또는 조건 해금

도덕성·정신력 시스템을 채택하기 전에는 현재 정화 기능만 유지한다.

## 명칭과 역할 정리 대기

다음 충돌은 건축물 트랙 재개 시 우선 정리한다.

- 현재 `여관`은 기능상 `용병 길드`에 가깝다.
- 초기 기획의 휴식용 여관을 별도 건축물로 유지할지 결정하지 않았다.
- 용병 명부는 현재 독립 패널이지만, 세계관상 주점·용병 길드·여관 중 어느 시설에 귀속할지 확정하지 않았다.
- 행동력 회복소는 현재 독립 시스템이며 교회의 오염도 정화와 혼합하지 않는다.

이름을 바꾸더라도 기존 Building ID나 저장 데이터를 즉시 변경하지 않는다. 먼저 표시 명칭과 역할을 확정한 뒤 마이그레이션 필요 여부를 판단한다.

## 기타 확장 가능성

아래 내용은 확정 작업이 아니라 구조적 여지만 남긴다.

- 건축물 해금 효과로 파티 최대 인원 `+1`
- 모집·정화·회복·생산 슬롯 확장
- 건축물 단계 또는 업그레이드
- 건축물에 용병을 배치해 활동시키는 기능
- 완공된 월드 건축물 버튼으로 관련 패널 직접 열기
  - 용병 길드 계열 → 모집 또는 용병 명부
  - 교회 → 기도·정화
  - 상점 → 구매·판매

캐릭터·퀘스트에 직접 사용되지 않는 확장 효과는 구현하지 않는다.

## 재개 조건

다음 조건을 충족한 뒤 건축물 기능 해금 트랙을 다시 검토한다.

1. 조건 기반 퀘스트 시스템의 최소 데이터 계약이 정해져 있다.
2. 대표 용병 2~3명의 등장·성장·개인 목표·귀환 조건이 설계되어 있다.
3. 해당 캐릭터 중 적어도 하나가 기존 건축물만으로는 충족할 수 없는 명확한 기능 요구를 가진다.
4. 그 요구가 새로운 메뉴를 늘리기 위한 것이 아니라 캐릭터 경험을 실제로 변화시킨다.
5. 방치형 컴패니언 흐름을 해치지 않고 짧은 개입으로 사용할 수 있다.

## 재개 시 권장 검토 순서

1. 현재 여관과 용병 길드의 명칭·역할 정리
2. 대표 캐릭터 퀘스트가 요구하는 건축 기능 추출
3. 대장간 필요 여부 및 장비·아이템 조건 계약 검토
4. 실제 재료 소비가 확정된 경우에만 광산 검토
5. 스트레스·도덕성·포만감·정신력 채택 여부 결정
6. 채택된 상태에 한해 휴식용 여관·주점·교회 확장 검토
7. 파티 정원·시설 슬롯·건물 업그레이드 같은 메타 확장은 마지막에 검토

## 현재 우선순위에서 제외하는 작업

- 신규 건축물 CSV·Generated 에셋 추가
- 신규 건축 UI와 월드 슬롯 제작
- 대장간 강화 로직
- 광산 생산·오프라인 정산
- 휴식용 여관의 복합 회복
- 스트레스·도덕성·포만감·정신력 저장 구조
- 주점 활동과 교회 도덕성 회복
- 건축물 업그레이드 및 슬롯 확장

캐릭터·퀘스트 작업 도중 위 기능이 필요해지면 곧바로 전체 트랙을 재개하지 않고, 필요한 계약만 이 문서에 추가한 뒤 최소 범위로 판단한다.
